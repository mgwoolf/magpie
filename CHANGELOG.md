## [0.1.0] - 2026-10-14

First public release.

### Added

- Logo search across Wikidata, Simple Icons, Wikimedia Commons and website favicons.
- Icon search across 200+ open-source icon sets via Iconify, with colour and icon-set locking.
- Stock photo search on Openverse, plus Pexels, Unsplash and Pixabay with your own API keys.
- SVG to transparent PNG conversion, by file picker or drag and drop.
- Copy any result to the clipboard as a transparent PNG.
- Mac-style interface: toolbar tabs, sidebar, resizable thumbnails, light/dark/auto appearance.
- Command-line tools: `search`, `icons`, `sets`, `photos`, `convert`, `clear-cache`.
- API keys stored in the OS keychain; on-disk cache for searches and downloads.
