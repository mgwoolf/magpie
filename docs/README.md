# Magpie developer docs

Start with [../AGENTS.md](../AGENTS.md) for commands and ground rules. Then:

| Doc | Read it when |
|-----|--------------|
| [architecture.md](architecture.md) | you need to know where code lives, how threads and messages work, or where data is stored |
| [ui-design.md](ui-design.md) | you're changing anything visible: colours, widgets, layout, text |
| [development.md](development.md) | you're building, testing or verifying, or following a recipe (new setting, tab, source, provider) |
| [egui-pitfalls.md](egui-pitfalls.md) | egui does something surprising |
| [decisions.md](decisions.md) | you want to know why something is the way it is, or plan to change it |
| [roadmap.md](roadmap.md) | you're looking for what to work on next |

User-facing documentation is the top-level [README](../README.md). Contribution guidelines are in
[CONTRIBUTING.md](../CONTRIBUTING.md).
